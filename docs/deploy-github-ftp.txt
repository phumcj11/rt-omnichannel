GitHub + Auto FTP Deploy — rt-omnichannel
==========================================

Repo: https://github.com/phumcj11/rt-omnichannel
Production URL: http://kan-mkt.com/rt/allchat
Remote folder: ./domains/kan-mkt.com/public_html/rt/allchat/

1) GitHub Secrets (Settings → Secrets and variables → Actions)
   FTP_SERVER   = ftp.idm-plus.com
   FTP_USERNAME = idmplusc
   FTP_PASSWORD = (รหัส FTP จริง — อย่า commit)

2) Deploy อัตโนมัติ
   - push ไป branch main → GitHub Actions รัน deploy.yml
   - ดูสถานะที่แท็บ Actions ใน repo

3) ไฟล์ที่ไม่ถูก deploy (exclude)
   - config/local.php
   - .github, .cursor, logs

4) ฐานข้อมูล production (สร้างแล้วบน hosting)
   Database: idmplusc_rt_allchat
   Host:     localhost
   Username: idmplusc_ipee
   Password: (จากหน้า hosting ตอนสร้าง DB)

   Import ตาราง:
   - เข้า phpMyAdmin บน hosting
   - เลือก DB idmplusc_rt_allchat
   - Import ไฟล์ database/schema.sql
   - ถ้าเคย import schema เก่าแล้ว ให้รัน database/migrations/002_facebook_pages.sql เพิ่ม

   หลัง import — เปลี่ยนรหัส admin ทันที (seed ใช้ admin123)

5) ครั้งแรกบนเซิร์ฟเวอร์ — สร้าง config/local.php
   คัดลอกจาก config/local.production.example.php แล้วใส่รหัส DB จริง:

   'base_path' => '/rt/allchat',
   'url'       => 'http://kan-mkt.com/rt/allchat',
   'env'       => 'production',
   'debug'     => false,
   'allow_dev_auto_login' => false,
   'database'  => [
     'host' => 'localhost',
     'name' => 'idmplusc_rt_allchat',
     'user' => 'idmplusc_ipee',
     'pass' => '...',
   ],

   อัปโหลดไฟล์ไปที่:
   domains/kan-mkt.com/public_html/rt/allchat/config/local.php
   (FTP หรือ File Manager — ไฟล์นี้ไม่มากับ deploy)

6) Facebook Webhook (production)
   Callback URL:
   http://kan-mkt.com/rt/allchat/webhooks/facebook.php
   (แนะนำ HTTPS เมื่อมี SSL)

7) ทดสอบหลัง deploy
   - เปิด http://kan-mkt.com/rt/allchat/
   - เปิด http://kan-mkt.com/rt/allchat/index.php (ต้องไม่ 404)
   - login / inbox / settings
   - Actions ใน GitHub ต้องเขียว (success)

8) แก้ 404 Not Found
   A) ไฟล์ยังไม่ขึ้นเซิร์ฟเวอร์
      - GitHub → Actions → ดู workflow ล่าสุด (ต้อง success)
      - ใส่ Secrets: FTP_SERVER, FTP_USERNAME, FTP_PASSWORD
      - Re-run workflow หรือ push commit ใหม่
      - เปิด FTP/File Manager ตรวจว่ามีไฟล์:
        domains/kan-mkt.com/public_html/rt/allchat/index.php

   B) มีไฟล์แต่ /login 404
      - ต้องมี .htaccess ในโฟลเดอร์ allchat (deploy มาจาก repo)
      - ต้องมี config/local.php บนเซิร์ฟเวอร์ (base_path = /rt/allchat)
      - hosting ต้องเปิด mod_rewrite + AllowOverride

   C) ถ้า FTP path ไม่ตรง
      - ลองดู root ตอน login FTP ว่าอยู่โฟลเดอร์ไหน
      - ปรับ server-dir ใน .github/workflows/deploy.yml ให้ชี้ถึง rt/allchat จริง
